## About

This repository hosts the published web edition of *Introduction to Healthcare
Data Analytics Using Excel*, an introductory textbook that teaches data
analytics through real healthcare examples using Microsoft Excel. It is written
for entry-level learners with no prior analytics background.

The web edition includes:

- Readable chapters, released gradually as the book progresses.
- A **Datasets** page with the synthetic teaching datasets used throughout the
  book, available for direct download.
- Light and dark reading modes, a per-chapter table of contents, and a
  responsive, mobile-friendly layout.

## What this repository is

This repository contains **only the generated static website** (HTML, CSS,
figures, and downloadable datasets). It is published automatically to GitHub
Pages.

- The manuscript source, build tooling, and instructor materials live in a
  separate private repository and are **not** part of this repo.
- Files here are generated by an automated build. **Do not edit them by hand**,
  as changes are overwritten on the next publish.

## Datasets

All teaching datasets on the site are **synthetic**. They contain no real
patient information and are provided so readers can practice freely. Each
dataset is documented on the site's [Datasets page](https://yar177.github.io/intro-to-HDA-site/datasets.html).
