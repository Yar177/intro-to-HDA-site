Datasets

The teaching datasets used throughout the book. They are synthetic, so you can practice freely without touching real patient information.

Use the file named in your chapter or assignment. Keep the original file unchanged so you can return to it. Where both clean and analytic versions exist, use the version the activity specifies.

Reference dimensions

Descriptive tables: who and where. One row per actor, no events.
