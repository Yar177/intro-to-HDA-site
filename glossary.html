Reference

Glossary

Terms are defined where they first appear in the chapters; this master glossary gathers them in one place.

Absolute reference
A cell reference locked with dollar signs so it does not move when copied, such as $B$2.
Action
A decision or change made in response to insight, such as adjusting reminder timing.
Adjusted R-squared
A version of R-squared that penalizes added predictors, used to compare models of different sizes.
Administrative code set
A code system that identifies services, products, or billing items, such as CPT or HCPCS Level II.
Analysis ToolPak
An add-in included with Excel that provides statistical procedures, including linear regression.
Analytic sample
The records finally used in an analysis, which may be smaller than the respondent sample after missing-data, eligibility, or analysis-specific exclusions.
Anecdotal evidence
A single vivid case offered in place of a sample; it cannot support a general claim.
Append
Stacking rows from files that share the same structure.
Assumptions
The conditions a recommendation depends on, disclosed so the decision-maker can weigh the risk.
AUROC
The area under the ROC curve; the probability the model ranks a random event case above a random non-case.
Baseline
A metric’s typical level over a longer period, used as the reference for judging change.
Benchmark
A reference point, such as a past baseline, a target, or a matched peer, used to judge whether a number is good.
Binary outcome
An outcome with two possible values, such as showed up or did not.
Blinding
Keeping participants or assessors unaware of group assignment so expectations do not color the result.
Blocking
Grouping similar units before randomizing within each block, to reduce variation attributable to the blocking factor.
Bottom line up front
The practice of stating the conclusion first and the supporting detail afterward.
Business associate
A person or organization that handles PHI on behalf of a covered entity, and is bound by HIPAA.
Calculation traceability
The ability to follow any result back to the rows and formulas that produced it; note this is not a formal change-history audit trail, which records who changed what and when.
Care setting
The place and mode in which care happens, such as an ambulatory clinic, an emergency department, a hospital, or a care-management program.
Classification
A code system that sorts clinical detail into a fixed set of reporting categories, such as ICD-10-CM.
Clinical analytics
Analysis focused on care processes and outcomes.
Clinical terminology
A code system that captures fine-grained clinical meaning and relationships, such as SNOMED CT.
Cluster sample
A sample of whole natural groups, such as clinics, with everyone in the chosen groups included.
Code set
A standardized list of categories used to record one part of care, such as ICD-10-CM for diagnoses.
Codebook
A record of each column’s name, meaning, type, and allowed values; also called a data dictionary.
Coefficient
The change in the outcome for a one-unit increase in a predictor, holding the other predictors constant.
Cohort study
An observational study that follows a defined group over time, prospectively or retrospectively, to see who develops an outcome.
Common-cause variation
The natural, expected wobble of a stable process from one period to the next.
Confidence interval
An estimate reported as a range, the point estimate plus and minus a margin of error, with a stated level of confidence.
Confounder
A variable related to both the exposure and the outcome and not on the causal pathway between them, which can explain an apparent link; it need not be hidden.
Confounding
When a predictor’s apparent effect is partly explained by another variable related to both it and the outcome.
Construct validity
The degree to which what a measure counts actually stands in for the thing the question is about.
Continuous variable
A quantitative variable measured on a scale that can take any value in a range, such as cost or minutes.
Continuum of care
The sequence of settings a patient moves through over time, from prevention and primary care through post-acute care; most continuity risk sits at the handoffs between them.
Control chart
A run chart with calculated limits that formally distinguish ordinary variation from signals.
Control group
The units in an experiment that do not receive the treatment under study, instead getting usual care, a placebo, or an alternative, used as a comparison.
Convenience sample
A sample of whoever is easiest to reach; cheap but prone to bias.
Correlation coefficient
A number from -1 to 1 measuring how tightly two numerical variables move together; written r.
Coverage error
The mismatch between the target population and the sampling frame: eligible people the frame omits, and ineligible people it wrongly includes.
Covered entity
A health plan, healthcare clearinghouse, or healthcare provider that transmits health information electronically in connection with HIPAA-standard transactions.
CPT
The American Medical Association’s licensed code set for outpatient and professional services.
Cross-sectional study
An observational study that measures a population at a single point in time.
Cumulative gains
A view of how much of an outcome is captured by acting on the top-ranked share of a population.
Dashboard
A small, curated set of views that supports recurring decisions.
Data
Raw observations, such as a single appointment date, diagnosis code, or survey response.
Data cleaning
The work of making a dataset trustworthy and ready for analysis.
Data dictionary
A document recording what each field means, its allowed values, and how it is calculated.
Data governance
The rules and roles that decide how data is defined, produced, and used.
Data lineage
The record of where a field came from and what was done to it along the way.
Data steward
A person accountable for a dataset who can say authoritatively what its fields mean.
Data use agreement
A contract under which a covered entity may share a limited data set for research, public health, or operations.
Data validation
A rule that restricts what a cell will accept when a value is typed in.
De-identification
The process of reducing identifiers until data no longer reasonably identifies anyone.
Decision brief
A short document that leads with a recommendation, then gives impact, a visual, assumptions, and limits.
Decision support
Analysis aimed at a specific choice someone must make, judged by whether it changes the action.
Denominator
The population the numerator events are drawn from.
Descriptive analytics
Analysis that describes what happened.
Descriptive statistics
Numbers that condense a column into a short summary of its center, spread, and shape.
Diagnostic analytics
Analysis that explores why something happened.
Dimension table
A table that describes the stable actors in the system, with one row per actor and no events.
Discrete variable
A quantitative variable that counts and takes separate, whole values, such as a number of visits.
Discrimination
A model’s ability to separate cases from non-cases, summarized by AUROC.
Drift
The decay of a model’s accuracy as the world it learned from changes over time.
Dummy variable
A variable that codes a category as 1 or 0 so a regression can use it; also called an indicator variable.
Dynamic array
A formula result that automatically spills across neighboring cells, available in Microsoft 365 and Excel 2021 or later.
ETL
Extract, transform, load; the general pattern of moving data from sources into an analysis-ready table.
Excel Table
A structured, named object Excel manages as a unit, expanding automatically when rows are added and supporting references by column name.
Experiment
A study that deliberately assigns a treatment to measure its effect, which can support a causal claim.
Expert Determination
The HIPAA de-identification method in which a qualified expert determines and documents that re-identification risk is very small.
Fact table
A table that records events, with one row per event and a time attached.
Financial analytics
Analysis focused on reimbursement, denials, payer mix, and margin.
Foreign key
A column in one table that refers to the primary key of another.
Formula
A cell entry beginning with an equals sign that computes a result from other cells.
Function
A named calculation that takes inputs in parentheses, such as AVERAGE(range).
HCPCS Level II
A code set for supplies, drugs, and non-physician services, maintained by CMS.
Health information exchange
The electronic infrastructure that lets separate organizations share a patient’s records when care crosses organizational lines.
Healthcare system
The loose network of settings, staff, and software through which care is delivered.
HIPAA
The Health Insurance Portability and Accountability Act, which sets US rules for using and disclosing PHI.
ICD-10-CM
The system of alphanumeric codes used in the United States to record diagnoses.
ICD-10-PCS
The code system used to record inpatient procedures.
Imputation
Filling a true missing value with an estimated one, as a documented and deliberate choice.
Inclusion and exclusion criteria
The rules that decide which records belong in the denominator.
Information
Data organized so that a pattern can be seen, such as a monthly no-show rate.
Insight
An answer to a question that matters, such as learning that no-shows are more common at some clinics than others.
Intercept
The predicted outcome when all predictors are zero; where the line crosses the axis.
Interquartile range (IQR)
The distance between the 25th and 75th percentiles, covering the middle half of the data.
Join
Combining two tables by matching a foreign key to a primary key, producing a wider table whose rows carry columns from both.
k-anonymity
A disclosure-risk property in which every record shares its quasi-identifier values with at least k minus 1 other records.
Least squares
The method that fits the line by minimizing the sum of squared residuals.
Levels
The distinct categories a qualitative variable can take.
Limitations
What an analysis cannot show or does not know, stated plainly.
Limited data set
PHI with direct identifiers removed but some dates and partial geography retained, shareable only under a data use agreement.
Linear regression
A model of a numerical outcome as a straight-line function of one or more predictors.
Log-odds
The logarithm of the odds of an event; logistic regression is linear in this quantity.
Logistic regression
A model that predicts the probability of a binary outcome, bounded between 0 and 1.
LOINC
The standard for identifying laboratory tests and clinical observations across systems; it does not encode the measured result value.
Master data
The authoritative record of core business entities, such as the patient, provider, and facility lists.
Mean
The arithmetic average of a set of values.
Measure
A precise, repeatable definition of something you can count or calculate.
Median
The middle value when the data is sorted; half of records fall below it.
Merge
Adding columns from a related table by matching on a shared key.
Metric
The number a measure produces when it is run on data.
Minimum necessary
The HIPAA standard of making a reasonable effort to limit PHI to what a task requires.
MS-DRG (Medicare Severity Diagnosis-Related Group)
A three-digit payment group that represents an inpatient stay for Medicare payment.
Multiple linear regression
A regression with more than one predictor, where each coefficient holds the others constant.
Multistage sample
A sample drawn in stages, such as selecting whole clusters first and then sampling within each.
Named range
A cell or range given a readable name so a constant or threshold can be defined once and reused.
NDC (National Drug Code)
A drug-product identifier assigned by the FDA as 10 digits in three segments, commonly normalized to 11 digits for billing; the FDA moves to a 12-digit format in 2033.
Neighborhood deprivation quintile
One of five equal-sized groups of neighborhoods ranked by a combined measure of socioeconomic disadvantage, from least to most deprived.
Nominal variable
A qualitative variable whose categories have no inherent order, such as visit type or payer.
Nonresponse bias
Distortion that occurs when those who do not respond differ from those who do.
Normal distribution
The idealized symmetric, bell-shaped distribution in which about 68 percent of values fall within one standard deviation of the mean and 95 percent within two.
Numerator
The events of interest being counted in a rate.
Observation
One row of a table; a single unit the data describes.
Observational study
A study that records what happens without intervening; it can show associations but cannot by itself establish causation.
Odds ratio
The exponentiated logistic coefficient; the factor by which a predictor multiplies the odds of the event.
Operational analytics
Analysis focused on the flow of work, such as access, staffing, and throughput.
Operational definition
A measure written in terms of the actual columns and values in the data, so that anyone can reproduce it.
Ordinal variable
A qualitative variable whose categories have a meaningful order but not necessarily equal gaps, such as a 1-to-5 satisfaction rating.
Outcome variable
The quantity a regression tries to explain; also called the dependent variable.
Outlier
A value far from the rest of the data.
p-value
The probability that chance alone would produce a difference at least as large as the one observed, if there were truly no difference.
Patient
The person who receives care; the party whose health the whole system exists to serve.
Payer
A party that finances care and administers coverage and payment, such as a private insurer, a self-funded employer, Medicare, or Medicaid.
PivotTable
A tool for rapidly summarizing tabular data by dragging fields into rows, columns, filters, and values.
Population health analytics
Analysis that looks across groups rather than single visits.
Power Query
Excel’s data preparation layer, which records refreshable import and cleaning steps.
Predictive analytics
Analysis that estimates what is likely to happen next.
Predictor
A variable used to explain the outcome; also called an independent variable.
Prescriptive analytics
Analysis that recommends what action to take.
Primary key
A column, or a combination of columns, whose value uniquely identifies each row of a table and is never missing.
Primary use
The operational job a piece of data was built to do in its source system.
Principal diagnosis
The condition found after study to be chiefly responsible for a hospital admission.
Projected impact
An honest estimate of what a recommended action will produce.
Protected health information (PHI)
Health data that can be tied to an identifiable individual, held by a covered entity or business associate.
Provider
A party that delivers and documents care, such as a hospital, clinician, or pharmacy.
Qualitative variable
A variable that holds a label placing a record in a group; also called categorical. It is either nominal or ordinal.
Quantitative variable
A variable that holds a numeric quantity you can do arithmetic on; also called numeric. It is either discrete or continuous.
Quasi-experimental study
A study that compares a treatment and a comparison group without full randomization; it can support causal claims under stated, defensible assumptions.
Quasi-identifier
A field that is not a direct identifier but can single out a person in combination, such as birth date, sex, and ZIP code.
R-squared
The share of the outcome’s variation that the model explains, from 0 to 1.
Randomization
Assigning units to treatment or control by chance so the groups are alike on average beforehand.
Range check
A validation that confirms a field’s values fall within an allowed set or interval.
Rate
A measure formed by dividing a numerator by a denominator over a fixed time window.
Raw data
Source data kept exactly as received, so it stays recoverable and auditable.
Re-identification
Linking apparently anonymous data back to a person, often by combining it with an outside source.
Reasonableness check
A quick, independent test that a result makes sense, such as confirming a filtered row count matches a formula’s denominator.
Reference data
A small, shared lookup list of valid values, such as facility types or payer categories.
Referential integrity
The property that every foreign key value exists in the table it points to.
Refresh
Re-running a query’s steps so new or updated source data flows through automatically.
Regulator
A stakeholder, such as CMS or NCQA, that defines how a measure must be calculated and can tie payment or a public rating to the result.
Relative reference
A cell reference that shifts when the formula is copied, such as B2.
Replication
Including enough units in each group that a chance difference is unlikely to be mistaken for a real effect.
Reproducibility
The property that a cleaning process can be rerun to produce the same result.
Residual
The difference between an actual value and the model’s prediction for it.
Respondent sample
The subset of the selected sample that actually responds or yields data.
Revenue code
A four-digit code on an institutional bill that marks where and what type of service was provided.
Risk adjustment
The use of diagnosis codes to account for how sick a population is, which affects payment.
Risk stratification
Sorting a population into tiers by predicted risk so resources can be targeted.
Run chart
A plot of a metric over time, read against its own baseline to separate signal from noise.
RxNorm
A terminology of normalized names for clinical drugs, maintained by the National Library of Medicine.
Safe Harbor
The HIPAA de-identification method that removes or reduces eighteen specified categories of identifier.
Sample
The records you observe. It narrows in two steps: the selected sample is what you draw from the frame, and the respondent sample is the subset that actually provides data.
Sampling frame
The list of records you can actually reach and sample from.
Secondary use
Any later use of the data to answer a question it was not originally designed for, which includes most analytics.
Selected sample
The records drawn from the sampling frame before any nonresponse.
Selection bias
Distortion that occurs when the way units enter the sample is related to what is being measured and is not corrected for, so the sample does not represent the population.
Signal
A change in a metric that reflects a real shift in the process, not ordinary variation.
Simple random sample
A sample in which every unit on the frame has an equal chance of selection.
Skew
Asymmetry in a distribution, where one tail is longer than the other.
Slope
The change in the outcome for a one-unit increase in a predictor.
SNOMED CT
A detailed clinical terminology used in electronic health records to capture findings and problems.
Solver
An Excel add-in for optimization, used later to fit a logistic regression by maximizing likelihood.
Source system
The software where a piece of data is first created, such as a scheduling system, electronic health record, or billing platform.
Spreadsheet-ready data
Data laid out tidily, with one row per unit, one variable per column, one value per cell, and consistent codes.
Stakeholder
Anyone with a stake in what the data says, such as a clinician, operations manager, finance leader, public health team, patient, or regulator.
Standard deviation
A measure of how far values typically fall from the mean, calculated in Excel with STDEV.
Standard error
A measure of how much a sample estimate would vary from sample to sample; it shrinks as the sample grows.
Stratified sample
A sample drawn separately within defined subgroups so each subgroup can be represented according to the allocation plan.
Structural missing
A blank that is correct because the value does not apply to that record.
Structured reference
A formula reference that uses a Table name and column name, such as Appointments[attendance_outcome], instead of cell coordinates.
Study design
The overall plan for how evidence is collected, such as a trial, cohort, or cross-sectional study.
Systematic review
A study that does not enroll new participants but systematically synthesizes evidence from existing studies; a meta-analysis pools their results statistically.
Systematic sample
A sample that takes every kth record from a random start in an ordered frame.
Table
A rectangle of data in which rows are records and columns are variables; also called a data matrix.
Target population
Everyone the question is about.
Threshold
The cutoff probability above which a predicted case is acted upon.
Tidy data
Data in which each row is one observation at a single grain and each column is one variable.
Transformation
Reshaping data into the form analysis needs without changing its meaning.
True missing
A blank where a value should exist but was not recorded.
Unit of analysis
What one row of a table represents; also called the grain. It decides what the table can count.
Validation
The set of checks that confirm the data means what the analyst thinks it means.
Variable
A column of a table, one attribute measured for every record.
Version control
Managing successive versions of files through clear naming and separation, so milestones are not lost.
Working data
The transformed copy of the data that analysis is actually built on.
XLOOKUP
A lookup function in Microsoft 365 and Excel 2021 or later that returns a value from one column matched on another; INDEX with MATCH is the older equivalent.
